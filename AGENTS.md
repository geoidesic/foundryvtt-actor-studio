## Project Setup

### Repository Structure
- Follow standard project conventions for the framework being used
- Keep configuration files at the root level
- Use `.gitignore` to exclude generated files and dependencies

### Development Environment
- Use Bun as the preferred package manager and runner. Use another package manager only when Bun cannot run the project's declared scripts.
